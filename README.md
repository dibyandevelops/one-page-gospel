# One Page Gospel

> The greatest news in human history: how a loving God rescues, redeems, and reconciles us to Himself through Jesus Christ — presented in a single, beautiful, interactive experience.

## ✨ Overview

**One Page Gospel** is a clean, accessible, and comprehensive single-page web presentation of the Christian Gospel. Designed for seekers, students, and believers alike, it features:

- **Guided Journey**: 5 core narrative pillars (Creation & Purpose, The Broken World & Separation, The Bridge: Jesus Christ, The Response: Faith & Grace, New Life & Walking Forward).
- **The Bridge Illustration**: An interactive visual diagram explaining how Jesus spans the infinite chasm of sin between humanity and God.
- **Multi-Translation Scripture Switcher**: Instant switching between **ESV**, **NIV**, and **KJV** translations with key verses and supporting scripture references.
- **1-Page Summary & Printable Tract**: A compact format optimized for quick reading and formatted to print cleanly on a single sheet of paper (`window.print()` / `Cmd+P`).
- **Adaptive Dark / Light Themes**: Refined typography (Inter & Cormorant Garamond) with accessible contrast and custom warm gold & deep slate palettes.
- **Prayer of Faith & Discipleship Next Steps**: A sample prayer of commitment with one-click copying and a 4-step checklist for walking forward.

## 🛠️ Technology Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **UI & State**: React 19, Lucide Icons, @tanstack/react-query

- **Type Safety**: TypeScript 5.9 (Strict mode) & Zod
- **Testing**: Vitest 2.1
- **Linting**: ESLint 9 (Flat Config)
- **Package Manager**: pnpm 10

## 🚀 Getting Started

### Prerequisites

- Node.js 22.x
- pnpm 10.x

### Installation

```bash
git clone https://github.com/dibyandevelops/one-page-gospel.git
cd one-page-gospel
pnpm install
```

### Development

```bash
pnpm dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### Scripts

- `pnpm dev`: Start development server with Turbopack
- `pnpm build`: Compile production build
- `pnpm start`: Start production server
- `pnpm test`: Run Vitest unit tests
- `pnpm lint`: Run ESLint checks
